# 谱Scan · PDF 五线谱转可编辑乐谱

手机端优先的纯前端网页应用：导入 PDF 乐谱，在浏览器本地识别五线谱，把结果变成可点击编辑的乐谱，并导出标准 MusicXML。

## 运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/`。手机与电脑在同一局域网时，可访问终端里显示的 `http://<电脑IP>:5173/`。

生产构建：

```bash
npm run build
npm run preview
```

## 功能

- **PDF 导入**：pdf.js 逐页渲染与预览，可切换页面后逐页识别。
- **钢琴大谱表识别**：自动把同一系统的高音谱表与低音谱表合并为一个钢琴声部，两行谱表的小节线对齐，并分别按高音/低音谱号换算音高。
- **本地识别（OMR）**：Web Worker 内完成灰度化、二值化、谱线分组、系统小节线检测、符头/符干/符尾分析，支持附点、八分/十六分音符与四分休止符。
- **可编辑乐谱**：自绘 SVG 大谱表，点击任意一行的音符即可修改音高、八度、升降号、时值、附点，支持和弦音增删、插入与删除音符。
- **全局设置**：标题、调号、拍号、速度，以及高音/低音谱表各自的谱号；支持撤销/重做。
- **导入导出**：导出带 `<staves>2</staves>` 与 `<backup>` 的 `.musicxml`，导入未压缩的 MusicXML，支持打印/另存为 PDF。
- **示例乐谱**：首页「先看看示例」可直接体验钢琴大谱表编辑流程。

## 识别能力与限制

浏览器内无法运行 Audiveris、oemer 等重型深度学习 OMR 引擎，本项目内置的是轻量启发式识别：

- 对**清晰的印刷谱**效果最好；扫描件、拍照、倾斜页面的识别率会明显下降。
- 默认按 4/4 拍、C 大调处理，识别后可在设置中修改拍号与调号。
- 已支持高/低音谱号、合并双谱表、小节线对齐、附点、八分/十六分音符与四分休止符识别。
- 暂不识别调号升降号（谱面调号需在设置中手动选择，音符升降号可逐个编辑），也不识别复杂连音、半/全休止符、歌词与多声部。
- 每个系统会自动合并为一个钢琴声部；暂不支持 `.mxl` 压缩包。

## 技术栈

- React + TypeScript + Vite
- pdfjs-dist（PDF 渲染）
- 自研 SVG 乐谱布局与渲染，Bravura 音乐字体（@vexflow-fonts/bravura）
- Web Worker（OMR 计算）
- MusicXML 4.0 读写
